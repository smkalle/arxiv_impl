# Employee Onboarding Guide

Welcome to the team. This guide walks you through your first week.

## Day 1: Account Setup

1. Create your company Google account at accounts.company.com
2. Set up two-factor authentication using Google Authenticator
3. Join the #general and #team-your-dept Slack channels
4. Complete the HR onboarding form in Workday

## Day 2: Tools and Access

Request access to the following tools via the IT portal:
- GitHub Enterprise (engineering teams)
- Jira project management
- Confluence knowledge base
- Figma design system (design and PM teams)

## Day 3: Codebase Orientation

Clone the main repository and run the local dev environment:

```bash
git clone https://github.com/company/main-repo
cd main-repo
make setup
make run
```

The local environment runs on port 3000. Ask your onboarding buddy for the database seed script.

## Day 4: First PR

Your first task is a good-first-issue. Pick one from the #good-first-issue Jira board.
Follow the PR template — it requires a description, linked issue, and test coverage.

## Day 5: Team Sync

Attend the weekly team sync at 10am on Fridays. Introduce yourself in #introductions.

## Contacts
